# 网易云 Enhanced 歌手接口实测

日期：2026-10-14。访问本机已配置的 Enhanced API，仅请求公开歌手数据，未发送账号 Cookie、读取凭据或修改服务配置。样本为周杰伦，歌手 ID `6452`。

## 详情字段

`GET /artist/detail?id=6452` 返回 HTTP 200、业务 `code=200`。

- 详情位于 `data.artist`，包含 `id`、`name`、`avatar`、`cover`、`briefDesc`。
- `avatar` 和 `cover` 是两个不同的公开图片地址；歌手头像使用 `avatar`。
- `musicSize=568` 是详情计数；歌曲分页接口返回 `total=566`，二者不同。分页必须使用歌曲接口自己的计数。
- `briefDesc` 返回多段文本，界面需按简短简介的约定控制展示长度。

## 排序与分页

请求为 `GET /artist/songs`，参数为 `id=6452`、`order=hot` 或 `order=time`、`limit=30`、`offset=(page-1)*30`。所有实测请求均返回 HTTP 200、业务 `code=200`。

响应顶层包含 `songs`、`more`、`total`、`code`，没有 `songCount`。歌曲包含 `id`、`name`、`dt`、`ar`、`al` 等现有转换器使用的字段。`ar` 同时保留每位歌手的 `id` 和 `name`；热门第一首为合唱，含温岚 `9612` 与周杰伦 `6452`。

对每种排序又请求了 `offset=0&limit=60`。它返回的全部 60 个歌曲 ID，均与两页 30 首按原顺序拼接完全一致；两页之间没有重复 ID。实测支持服务端先排序再分页，客户端应保留接口顺序，不对当前页重新排序。

## 证据范围

本次确认 `hot` 和 `time` 返回不同顺序，分页前缀一致，末页和越界页的 `more` 符合预期。歌曲及其 `al` 字段未返回 `publishTime`，因此没有在客户端独立证明每首歌曲的发行时间递减；“最新”采用接口的 `order=time` 顺序。

这里只核实了一个歌手在当前服务的公开元数据，没有核实登录后的可播放性。元数据存在不代表歌曲有播放权限；播放失败继续使用现有处理逻辑。
