# 歌手页、喜欢标记与底部切歌需求

状态：需求澄清完成，尚未实施。QQ 热门／最新排序能力仍需验证。

正式规格见 [歌手与浏览功能规格](artist-and-browse-spec.md)，已发布为 [GitHub Issue #10](https://github.com/FlyTOmeLight/music-tui/issues/10)。后续实现与任务拆分以正式规格为准；本文保留需求澄清记录。

## 已确定的范围

- 支持 QQ 音乐与网易云 Enhanced。
- 用户确认网易云官方模式已废弃，不纳入本次功能设计。
- 增加可从歌手名称进入的歌手详情页，并提供歌曲列表排序。
- 歌手歌曲按「热门／最新」对全部歌曲排序，再分页显示；不以当前页局部排序替代。
- 歌手详情页展示头像、姓名、简短简介和歌曲列表，本次不增加专辑列表与专辑入口。
- 合唱歌曲中，各歌手名称分别可点击，直接进入对应歌手页；键盘操作提供歌手选择框。
- 搜索结果展示当前账号的歌曲喜欢状态。
- 搜索结果的喜欢标记可点击，执行喜欢／取消喜欢；保留 `S` 键操作，成功后同步更新状态。
- 喜欢标记采用 `♥`（已喜欢）、`♡`（未喜欢）；未登录或查询失败显示 `?`，不当作未喜欢。
- 主界面底部播放区域增加可点击的上一首、下一首控件。
- 底部提供「上一首、暂停／继续、下一首」三个按钮，保留现有快捷键，并适配 80×24 终端。
- 从歌手页选歌后，顺序播放沿选定的热门／最新列表跨页继续；随机、单曲循环和手动待播遵循现有规则。
- 仅浏览歌手页或切换排序不改变当前播放队列；下一次从列表选歌时才建立对应顺序的播放队列。

## 设计默认值

- 歌手歌曲默认按热门排列。
- 歌曲列表、底部当前歌曲区域和独立播放页的歌手名均提供详情页入口。
- 返回时恢复原浏览列表、页码与选中歌曲。
- 喜欢状态查询失败可重试；点击修改失败时保留上次确认的状态并显示错误，成功后更新当前账号的状态。
- 喜欢标记的本次需求范围为搜索结果，其他列表不作为本次验收要求。

## 验收条件

- QQ 与网易云 Enhanced 均能从歌手名进入指定歌手页；合唱歌曲可选择每位歌手。
- 页面展示头像、姓名、简短简介及分页歌曲列表；简介或头像缺失不阻止浏览歌曲。
- 热门／最新顺序覆盖全部歌曲，跨页保持一致，不能用本页排序冒充全列表排序。
- 从排序结果选歌后，顺序播放按选定列表跨页继续；浏览、返回及排序切换本身不打断播放。
- 搜索结果显示已喜欢、未喜欢或未知状态；鼠标与 `S` 键修改成功后显示一致，账号切换后不沿用其他账号的喜欢状态。
- 底部三个播放按钮与现有快捷键使用相同播放行为，暂停按钮随状态切换为继续；80×24 下可见且可操作。

## 当前实现与调查依据

- `Track` 仅保存合并后的歌手名称，进入指定歌手页面需要保留歌手身份。
- 现有歌曲列表排序仅作用于当前页，支持原序、歌名、歌手和时长。
- 独立播放页已有上一首、暂停、下一首按钮，底部切歌可以复用现有播放动作。
- QQ 已安装 SDK 有歌手详情与分页歌曲接口，歌曲排序参数固定为 `1`；其他排序值尚未验证。
- 本机网易云 Enhanced 模块提供歌手详情与分页歌曲接口，并接受热门、时间排序参数；尚未实测响应。
- 两个平台均已有喜欢状态查询，但当前逐曲查询会重复获取完整喜欢列表。
- 仓库仍保留官方模式实现及可选接入文档，与用户确认的废弃状态存在差异。本次按用户确认的范围设计。

## 实现前核实与实现时验证

- 核实 QQ 热门／最新排序的真实参数、返回顺序和分页行为；如无法支持，需重新讨论该平台的排序方案，不能静默降为本页排序。
- 实测网易云 Enhanced 歌手详情、热门／最新排序与分页响应。
- 结合终端布局确定喜欢标记和底部按钮位置，并检查更窄终端下的显示。
